Nossos Projetos Acadêmicos

Projetos práticos desenvolvidos durante nossa graduação na FICR, aplicando clean code, usabilidade e engenharia de software.

Banco de Dados & Autenticação Por Luiz Fernando

Sistema de Autenticação, Cadastro e Gestão de Usuários

Desenvolvimento de um sistema completo de tela de cadastro e autenticação de usuários. O projeto prioriza a validação estrita de campos, prevenção de entradas inválidas, usabilidade intuitiva e estrutura pronta para conexão segura com banco de dados relacional.

✓ Validação de Formulários em Tempo Real
✓ Estrutura Preparada para SQL Relacional
✓ Interface Limpa e Acessível
HTML5 Semântico CSS3 Flexbox Modelagem de Dados Git / GitHub
Front-end & Performance Por Jonas Gabriel

Interface de Busca Minimalista de Alta Performance

Aplicação web inspirada no layout da página inicial do Google, com foco em design minimalista, tempo de resposta imediato e barra de busca centralizada. O projeto explora a maestria de regras de layout em CSS moderno, acessibilidade de teclado e responsividade absoluta.

✓ Layout Minimalista e Foco Visual
✓ Foco Automático e Atalhos de Teclado
✓ 100% Responsivo para Qualquer Dispositivo
HTML5 CSS Moderno Automação Python Performance Web
Redes & Suporte Corporativo Por Joan Antonio

Portal de Gestão de Suporte & Monitoramento de Redes

Ambiente centralizado para abertura e acompanhamento de chamados de suporte técnico, com simulação de disponibilidade de servidores em topologia de rede local (TCP/IP e DNS). Criado para reduzir gargalos operacionais e garantir resolução ágil de problemas de hardware e conectividade.

✓ Simulação de Status de Serviços (DNS / Gateway)
✓ Gestão de Chamados por Nível de Severidade
✓ Políticas de Segurança da Informação
Redes TCP/IP DNS & DHCP JavaScript Segurança Básica
